# Neovim Cheatsheet

My go-to commands for Neovim that I actually use daily.

## Getting Started

**Launch Neovim**
```bash
nvim                    # Open in current directory
nvim config.json        # Open specific file
nvim app.js server.js   # Open multiple files in buffers
```

**Open files in different layouts**
```bash
nvim -p index.html style.css script.js  # Each file in its own tab
nvim -o main.py utils.py                # Horizontal splits
nvim -O client.go server.go             # Vertical splits
```

## Window Splits & Navigation

**Creating splits:**
```vim
:split filename         # Horizontal split with file
:vsplit filename        # Vertical split with file
:sp                     # Horizontal split (same file)
:vsp                    # Vertical split (same file)
Ctrl+w s                # Horizontal split (same file)
Ctrl+w v                # Vertical split (same file)
```

**Navigating between splits:**
```vim
Ctrl+w h                # Move to left split
Ctrl+w j                # Move to bottom split
Ctrl+w k                # Move to top split
Ctrl+w l                # Move to right split
Ctrl+w w                # Cycle through splits
```

**Resizing splits:**
```vim
Ctrl+w =                # Make all splits equal size
Ctrl+w +                # Increase height
Ctrl+w -                # Decrease height
Ctrl+w >                # Increase width
Ctrl+w <                # Decrease width
:resize 20              # Set height to 20 lines
:vertical resize 80     # Set width to 80 columns
```

**Closing splits:**
```vim
Ctrl+w q                # Close current split
Ctrl+w o                # Close all splits except current
:only                   # Same as Ctrl+w o
```

## Navigation & Buffers

**Buffer management** (when you have multiple files open):
```vim
:buffers                # List all open buffers
:b 2                    # Switch to buffer 2 (main.py)
:bd                     # Close current buffer
:bd!                    # Force close without saving
```

**Quick file switching:**
```vim
Ctrl+^                  # Switch to previous buffer
:e routes.js            # Open/edit another file
```

## Marks

**Setting and using marks:**
```vim
ma                      # Set mark 'a' at current position
'a                      # Jump to mark 'a'
`a                      # Jump to exact position of mark 'a'
:marks                  # List all marks
```

**Automatic marks:**
```vim
''                      # Jump to previous position
'.                      # Jump to last edit
'^                      # Jump to last insert
```

**Example workflow:**
1. `ma` - mark current function as 'a'
2. Navigate elsewhere in file
3. `'a` - quickly return to that function

## Registers

**Using registers (clipboard system):**
```vim
"ay                     # Copy to register 'a'
"ap                     # Paste from register 'a'
"Ay                     # Append to register 'a'
:reg                    # Show all registers
:reg a                  # Show register 'a' contents
```

**Special registers:**
```vim
"0p                     # Paste last yanked text (not deleted)
"+y                     # Copy to system clipboard
"+p                     # Paste from system clipboard
"*y                     # Copy to selection clipboard (X11)
```

**Example workflow:**
1. `"ay3dd` - delete 3 lines into register 'a'
2. Navigate elsewhere
3. `"ap` - paste those 3 lines

## Text Selection & Ranges

These ranges work with most commands (`:delete`, `:substitute`, etc.):

| Range | What it selects | Example |
|-------|----------------|---------|
| `:5` | Line 5 only | `:5d` (delete line 5) |
| `:5,10` | Lines 5 through 10 | `:5,10s/var/let/g` |
| `:%` | Entire file | `:%s/TODO/DONE/g` |
| `:.` | Current line | `:.s/foo/bar/` |
| `:$` | Last line | `:$d` (delete last line) |
| `:'<,'>` | Visually selected text | Select text, then `:'<,'>s/old/new/g` |
| `:/function/` | Line matching pattern | `:/function/,/}/d` (delete function block) |

## Search & Replace

**Basic search:**
```vim
/import                 # Search forward for "import"
?export                 # Search backward for "export"
n                       # Next match
N                       # Previous match
```

**Find and replace:**
```vim
:%s/var/let/g           # Replace all "var" with "let" in file
:5,10s/console.log/logger.info/g  # Replace in lines 5-10 only
:%s/TODO/DONE/gc        # Replace with confirmation for each
:%s/\<old\>/new/g       # Replace whole word "old" with "new"
```

**Real examples I use:**
```vim
:%s/localhost:3000/api.example.com/g  # Update API endpoints
:%s/== null/=== null/g                # Fix equality comparisons
```

## Command Line Tricks

**Insert from registers in command mode:**
```vim
Ctrl+r "                # Insert unnamed register
Ctrl+r a                # Insert register 'a'
Ctrl+r +                # Insert system clipboard
Ctrl+r %                # Insert current filename
Ctrl+r /                # Insert last search pattern
```

**Example:** Type `:e ` then `Ctrl+r %` to edit file in same directory.

**Other command line operations:**
```vim
:!ls -la                # Run shell command
:!git status            # Check git status
:r !date                # Insert current date/time
:r !curl -s api.com/data | jq  # Insert API response
:w !sudo tee %          # Save file as root (when you forgot sudo)
```

## External Commands

**Filter text through external commands:**
```vim
:%!jq                   # Format entire file as JSON
:%!sort                 # Sort all lines alphabetically
:'<,'>!sort             # Sort only selected lines
:%!prettier --stdin-filepath %  # Format with Prettier
```

**Real examples:**
```vim
:%!avro-tools tojson % | jq    # Convert Avro to formatted JSON
:%!python -m json.tool         # Format JSON using Python
:'<,'>!column -t               # Align selected columns
```

## Key Bindings & Configuration

**Finding existing key mappings:**
```vim
:map                    # Show all mappings
:nmap                   # Show normal mode mappings
:imap                   # Show insert mode mappings
:map <leader>           # Show all leader key mappings
:verbose map <C-p>      # Show where Ctrl+P mapping was defined
```

**Creating custom mappings in your config:**
```lua
-- In ~/.config/nvim/init.lua
vim.keymap.set('n', '<leader>w', ':w<CR>', { desc = 'Save file' })
vim.keymap.set('n', '<C-h>', '<C-w>h', { desc = 'Move to left split' })
vim.keymap.set('i', 'jk', '<Esc>', { desc = 'Exit insert mode' })
vim.keymap.set('v', '<leader>s', ':sort<CR>', { desc = 'Sort selection' })
```

**Which-Key plugin (shows available keybindings):**
```lua
-- Add to your config
require('which-key').register({
  ['<leader>f'] = { name = '+file' },
  ['<leader>g'] = { name = '+git' },
  ['<leader>s'] = { name = '+search' },
})
```

When you press `<leader>` and wait, Which-Key shows available completions.

## Essential Movements

```vim
gg                      # Go to top of file
G                       # Go to bottom of file
0                       # Beginning of line (column 0)
$                       # End of line
w                       # Next word start
b                       # Previous word start
}                       # Next empty line (paragraph)
{                       # Previous empty line
15G                     # Go to line 15
```

## Quick Edits

```vim
dd                      # Delete current line
3dd                     # Delete 3 lines starting from current
yy                      # Copy current line
5yy                     # Copy 5 lines
p                       # Paste after cursor
P                       # Paste before cursor
u                       # Undo last change
Ctrl+r                  # Redo
.                       # Repeat last command
```

## Visual Mode

```vim
v                       # Character-wise visual
V                       # Line-wise visual (select whole lines)
Ctrl+v                  # Block visual (select columns)
```

**Example workflow:**
1. `V` to enter line visual mode
2. `5j` to select 5 lines down
3. `:s/old/new/g` to replace in selection

**Useful file operations:**
```vim
:w backup.js            # Save copy as backup.js
:saveas config-new.json # Save current buffer with new name

            <td><code>:%s/TODO/DONE/g</code></td>
          </tr>
          <tr>
            <td><code>:.</code></td>
            <td>Current line</td>
            <td><code>:.s/foo/bar/</code></td>
          </tr>
          <tr>
            <td><code>:$</code></td>
            <td>Last line</td>
            <td><code>:$d</code> (delete last line)</td>
          </tr>
          <tr>
            <td><code>:'&#x3C;,'></code></td>
            <td>Visually selected text</td>
            <td>Select text, then <code>:'&#x3C;,'>s/old/new/g</code></td>
          </tr>
          <tr>
            <td><code>:/function/</code></td>
            <td>Line matching pattern</td>
            <td><code>:/function/,/}/d</code> (delete function block)</td>
          </tr>
        </tbody>
      </table>
    </div>
    <h2 id="search--replace">Search &#x26; Replace</h2>
    <p><strong>Basic search:</strong></p>
    <pre><code class="hljs language-vim">/import                 # Search forward for "import"
?export                 # Search backward for "export"
n                       # Next match
N                       # Previous match
</code></pre>
    <p><strong>Find and replace:</strong></p>
    <pre><code class="hljs language-vim">:%s/var/let/g           # Replace all "var" with "let" in file
:5,10s/console.log/logger.info/g  # Replace in lines 5-10 only
:%s/TODO/DONE/gc        # Replace with confirmation for each
:%s/\&#x3C;old\>/new/g       # Replace whole word "old" with "new"
</code></pre>
    <p><strong>Real examples I use:</strong></p>
    <pre><code class="hljs language-vim">:%s/localhost:3000/api.example.com/g  # Update API endpoints
:%s/== null/=== null/g                # Fix equality comparisons
</code></pre>
    <h2 id="command-line-tricks">Command Line Tricks</h2>
    <p><strong>Insert from registers in command mode:</strong></p>
    <pre><code class="hljs language-vim">Ctrl+r "                # Insert unnamed register
Ctrl+r a                # Insert register 'a'
Ctrl+r +                # Insert system clipboard
Ctrl+r %                # Insert current filename
Ctrl+r /                # Insert last search pattern
</code></pre>
    <p><strong>Example:</strong> Type <code>:e </code>then <code>Ctrl+r %</code> to edit file in same directory.</p>
    <p><strong>Other command line operations:</strong></p>
    <pre><code class="hljs language-vim">:!ls -la                # Run shell command
:!git status            # Check git status
:r !date                # Insert current date/time
:r !curl -s api.com/data | jq  # Insert API response
:w !sudo tee %          # Save file as root (when you forgot sudo)
</code></pre>
    <h2 id="external-commands">External Commands</h2>
    <p><strong>Filter text through external commands:</strong></p>
    <pre><code class="hljs language-vim">:%!jq                   # Format entire file as JSON
:%!sort                 # Sort all lines alphabetically
:'&#x3C;,'>!sort             # Sort only selected lines
:%!prettier --stdin-filepath %  # Format with Prettier
</code></pre>
    <p><strong>Real examples:</strong></p>
    <pre><code class="hljs language-vim">:%!avro-tools tojson % | jq    # Convert Avro to formatted JSON
:%!python -m json.tool         # Format JSON using Python
:'&#x3C;,'>!column -t               # Align selected columns
</code></pre>
    <h2 id="key-bindings--configuration">Key Bindings &#x26; Configuration</h2>
    <p><strong>Finding existing key mappings:</strong></p>
    <pre><code class="hljs language-vim">:map                    # Show all mappings
:nmap                   # Show normal mode mappings
:imap                   # Show insert mode mappings
:map &#x3C;leader>           # Show all leader key mappings
:verbose map &#x3C;C-p>      # Show where Ctrl+P mapping was defined
</code></pre>
    <p><strong>Creating custom mappings in your config:</strong></p>
    <pre><code class="hljs language-lua"><span class="hljs-comment">-- In ~/.config/nvim/init.lua</span>
vim.keymap.set(<span class="hljs-string">'n'</span>, <span class="hljs-string">'&#x3C;leader>w'</span>, <span class="hljs-string">':w&#x3C;CR>'</span>, { desc = <span class="hljs-string">'Save file'</span> })
vim.keymap.set(<span class="hljs-string">'n'</span>, <span class="hljs-string">'&#x3C;C-h>'</span>, <span class="hljs-string">'&#x3C;C-w>h'</span>, { desc = <span class="hljs-string">'Move to left split'</span> })
vim.keymap.set(<span class="hljs-string">'i'</span>, <span class="hljs-string">'jk'</span>, <span class="hljs-string">'&#x3C;Esc>'</span>, { desc = <span class="hljs-string">'Exit insert mode'</span> })
vim.keymap.set(<span class="hljs-string">'v'</span>, <span class="hljs-string">'&#x3C;leader>s'</span>, <span class="hljs-string">':sort&#x3C;CR>'</span>, { desc = <span class="hljs-string">'Sort selection'</span> })
</code></pre>
    <p><strong>Which-Key plugin (shows available keybindings):</strong></p>
    <pre><code class="hljs language-lua"><span class="hljs-comment">-- Add to your config</span>
<span class="hljs-built_in">require</span>(<span class="hljs-string">'which-key'</span>).register({
  [<span class="hljs-string">'&#x3C;leader>f'</span>] = { name = <span class="hljs-string">'+file'</span> },
  [<span class="hljs-string">'&#x3C;leader>g'</span>] = { name = <span class="hljs-string">'+git'</span> },
  [<span class="hljs-string">'&#x3C;leader>s'</span>] = { name = <span class="hljs-string">'+search'</span> },
})
</code></pre>
    <p>When you press <code>&#x3C;leader></code> and wait, Which-Key shows available completions.</p>

    <pre><code class="hljs language-vim">gg                      # Go to top of file

</code></pre>

    <pre><code class="hljs language-vim">dd                      # Delete current line

p                       # Paste after cursor
P                       # Paste before cursor
u                       # Undo last change
Ctrl+r                  # Redo
.                       # Repeat last command
</code></pre>
    <h2 id="visual-mode">Visual Mode</h2>
    <pre><code class="hljs language-vim">v                       # Character-wise visual

Ctrl+v                  # Block visual (select columns)
</code></pre>

    <ol>
      <li><code>V</code> to enter line visual mode</li>
      <li><code>5j</code> to select 5 lines down</li>
      <li><code>:s/old/new/g</code> to replace in selection</li>
    </ol>
